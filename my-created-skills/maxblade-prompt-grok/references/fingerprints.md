# MaxBlade prompt-block fingerprints — v2 (pattern rules)

Supersedes phrase-only detection. Use with `MAXBLADE_ALIEN_SCALE.md`.

## Detect “he is prompting” (across VODs)
- Agent address: tell/spawn/open Chase|Claude|Claw code|Marshall
- Then first-person build verb: build me / I want you to build / vibe code
- Then **accretion**: ≥3 “I want/I need/and” clauses OR stacked sensory nouns
- Optional close: do not stop / perfect / playable / AAA / show me your full capability
- Optional pep nuke or post-nuke apology within ~30s after handoff completes

## Not a prompt dump
- Pure chat reading, donation thanks, settings help
- Single short UI command without accretion
- Model benchmarking talk without a world/sim ask

triple A / AAA, lawn mower/lawnmower simulator, Walmart simulator, visually impressive, photorealistic, do not stop until, tell Chase, lock in, wake, beyond
