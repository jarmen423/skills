# Alien delivery scale (reference)

Lab nickname for MaxBlade prompt-dump intensity (1–10). Behaviors from seed VODs; labels are ours.

## Scale

| Level | Register | What it sounds like |
|------|----------|---------------------|
| 1 | Ops flat | Short canvas / agent logistics |
| 2 | Soft please | Can you please… |
| 3 | Warm affirm bridge | You’re incredible/amazing → next ask |
| 4 | House DJ | Come on / baby / let’s go / all righty |
| 5 | Psychosis coach | Lock in / wake / creatinated·caffeinated / “I want you psychotic” |
| 6 | Spec stacking | I want / I need accretion starts |
| 7 | Cinematic / SKU fetish | Worldbuild OR barcode-level detail |
| 8 | AAA / beyond / don’t-stop | Grade + perfect / playable / brilliant close |
| 9 | Pep nuke (tip only) | Short wake / model-to-do-it baby |
| 10 | Post-nuke grin | Sorry / ahead of myself / out of control / not gonna lie |

**Full dump default ~8.5:** levels 6–8 for the body; tip 9 on the last line; optional 10 after.

**Anti-patterns:** calm narrator at 8–9; scrubbing fillers; bullets instead of accretion; level 9 for the whole body.
