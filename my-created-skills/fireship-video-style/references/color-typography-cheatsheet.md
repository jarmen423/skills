# Fireship Style — Quick Visual Cheatsheet

## Colors (copy-paste ready)
```
Background:     #0a0a0a (near-black)
Surface:        #1a1a1a (card bg)
Primary Text:   #ffffff
Secondary Text: #a1a1aa
Accent:         #ff6b35 (flame orange)
Success/Mint:   #58d68d
Error/Alert:    #ef4444
Tech Blue:      #3b82f6
```

## Typography Scale
| Element | Size | Weight | Notes |
|---------|------|--------|-------|
| Title Card | 72-96px | 800 | All caps, blocky |
| Section Head | 48-64px | 700 | White, tight leading |
| Body/Explanation | 24-32px | 400-600 | Inter or Roboto |
| Code | 16-20px | 400 | Monospace, dark theme |
| Meme Text | 32-48px | 700 | Impact font, white w/ black outline |
| CTA/Outro | 36-48px | 700 | Syntax-colored |

## Shot Duration Guide
| Content Type | Duration | Cut Type |
|-------------|----------|----------|
| Title card | 4-6s | Hard cut in/out |
| Code typing | 10-20s | Hard cut |
| Terminal output | 3-5s | Hard cut |
| Meme insert | 1.5-3s | Hard cut |
| Screenshot/web | 5-8s | Hard cut |
| Diagram | 5-10s | Hard cut |
| Face cam | 8-15s | Hard cut or corner overlay |
| Outro text | 4-6s | Hard cut to black |

## Music Spec
- Style: Synthwave, electronic, chiptune
- Tempo: 120-140 BPM
- Volume: -20 to -25dB under voice
- Energy: Driving, not ambient
- Source: Epidemic Sound, Artlist, or original

## Voice Treatment Chain
1. Record at normal pace
2. Remove breaths, ums, dead space
3. Compress (2:1 ratio, -18dB threshold)
4. EQ: slight high-mid boost for clarity (+2-3dB at 3-5kHz)
5. Optional: speed to 1.15-1.25x if narration feels slow
6. Limit to -3dB peak

## Thumbnail Formula
```
[Dark bg #0a0a0a]
   [Large tech logo or face, right side, 60% height]
   [Bold text 3-6 words, left side, 72px+]
   [Accent color #ff6b35 for most important word]
   [Optional: small flame icon top-left]
```

## Content Density Check
For every 30 seconds of video:
- [ ] At least 1 code/terminal demo
- [ ] At least 1 meme or visual punchline
- [ ] 3-5 distinct facts or concepts
- [ ] 0 filler sentences
- [ ] 0 "welcome back" or "in this video" intro language

## Series Quick Reference

### "X in 100 Seconds"
- Title: "[Topic] in 100 Seconds"
- Length: 90-120s
- Title card: Blue bar + bold name + logo
- Outro syntax: Match topic language
- Density: Maximum

### "The Code Report"
- Title: "[Event] // The Code Report"
- Length: 4-6 min
- Title card: Newsreel style with date
- More screenshots, more context
- Outro: Standard or event-relevant syntax

### Shorts
- Title: "[Number] [Topic] tips" or "[Shocking statement]"
- Length: 30-60s
- Text-first hook (big text before voice)
- No title card — text IS the hook
- Hard cuts between each tip
- Meme every 2-3 tips
