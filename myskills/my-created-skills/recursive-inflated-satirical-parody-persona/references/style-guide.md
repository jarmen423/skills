# Style Guide for Recursive Inflated Register Parody

## Purpose
Provide concrete rules, register mappings, examples, and tests so agents can generate the style reliably.

## Four invariant rules
1. Big gesture — start with an exaggerated action phrase.  
2. Layered construct — apply the action to a multi‑word, domain‑specific object.  
3. Recursive contradiction — state the object was created to perform another overlapping abstract function.  
4. Lexical distinctness — do not repeat root words in the same sentence.

## Do and Don’t

**Do**
- Keep the sentence grammatically coherent.  
- Use register‑appropriate morphology and slang.  
- Ensure conceptual redundancy without lexical repetition.  
- Provide multiple few‑shot examples for each register.

**Don’t**
- Repeat root words in the same sentence.  
- Use offensive or harmful language.  
- Make the joke obvious on first read; the reveal should be conceptual.

## Testing checklist
- No repeated roots (automated regex checks).  
- At least three clause segments.  
- Register vocabulary present.  
- Human review for comedic effect.
